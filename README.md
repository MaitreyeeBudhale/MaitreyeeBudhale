## 🚀 Featured Projects

### 🔥 HeatVision
**Computer Vision · Python · YOLO · ByteTrack**

A computer vision-based analytics system that processes CCTV footage to track customer movements, analyze trajectories, and generate heatmaps for visualizing movement patterns in retail environments.

**Key Features**
- 🎯 Person detection and multi-object tracking.
- 🗺️ Trajectory analysis and movement visualization.
- 🔥 Heatmap generation on video frames and store blueprints.
- 📍 Spatial mapping of customer movements.

---

### 🧠 Pathwise
**React · Node.js · Express.js · MongoDB · Generative AI · RAG**

An AI-powered personalized learning platform that transforms uploaded PDF documents into structured learning roadmaps and enables users to interact with their learning materials through an intelligent document chatbot.

**Key Features**
- 📚 Automated learning roadmap generation with milestones and estimated durations.
- 💬 Chat with PDF using Retrieval-Augmented Generation (RAG).
- 🔎 Semantic search using vector embeddings and MongoDB Atlas Vector Search.
- ⚙️ Asynchronous processing using BullMQ and Redis.

---

### 🚗 Ride Sharing
**React · Node.js · Express.js · MongoDB · Redis · Socket.IO**

A ride-sharing application designed to connect riders with drivers through location-based matching and real-time communication.

**Key Features**
- 📍 Real-time location updates using Socket.IO.
- 🗺️ Location autocomplete and route integration using Google Maps APIs.
- ⚡ Geospatial operations and location-based matching using Redis.
- 🔄 Ride management and route-based matching logic.
